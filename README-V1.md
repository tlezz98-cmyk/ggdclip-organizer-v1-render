# Clip Organizer V1

## เปิดใช้งานแบบไม่ใช้ Command Prompt

บน Windows ให้ดับเบิลคลิก `Open Clip Organizer.vbs` ได้เลย ไฟล์นี้จะเปิดแอพแบบซ่อนหน้าต่างคำสั่ง และเปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8787/`

ถ้าเครื่องยังไม่มี Node.js ให้ติดตั้ง Node.js LTS ก่อนหนึ่งครั้ง

## โหมดออนไลน์ / ชีตส่วนตัว

แอพรองรับ Google Login สำหรับอ่าน Google Sheet / Google Drive ที่ไม่ได้เปิดสาธารณะแล้ว โดยอีเมลที่อนุญาตค่าเริ่มต้นคือ:

- `suntzu.tutor.official@gmail.com`
- `tlezz98@gmail.com`

ถ้าจะใช้กับชีต private ให้ตั้งค่า Google OAuth ใน `config.json` ก่อน:

```json
"googleOAuth": {
  "clientId": "ใส่ Google OAuth Client ID",
  "clientSecret": "ใส่ Google OAuth Client Secret",
  "redirectUri": "http://127.0.0.1:8787/auth/google/callback"
}
```

สำหรับนำขึ้นออนไลน์ ให้เปลี่ยน `redirectUri` เป็นโดเมนจริง เช่น `https://your-domain.com/auth/google/callback` และตั้ง `COOKIE_SECURE=1`

แท็บที่เหมาะกับออนไลน์หลายคนคือ `Dashboard ตำแหน่ง`, `ค้นคลังทั้งหมด`, และ `คลังเอกสาร` ส่วน `จัดคลิปตามตำแหน่ง` ยังเป็นโหมด local เพราะอ้างอิงไฟล์คลิปในเครื่อง

แอพ local สำหรับจัดคลิปคอร์สเรียนตามรายวิชา/ตำแหน่งงานจาก Google Sheet โดยใช้ Hard Link เพื่อลดการคัดลอกไฟล์วิดีโอขนาดใหญ่

## วิธีเปิด

1. ดับเบิลคลิก `start-v1.cmd`
2. แอพจะเปิดที่ `http://127.0.0.1:8787/`
3. ใส่หรือเช็กค่า:
   - Google Sheet URL
   - โฟลเดอร์ต้นทางคลิป
   - โฟลเดอร์ปลายทาง
4. กด `สแกน`
5. โหลดตำแหน่ง/รายวิชา
6. ตรวจคลิปด้วยปุ่ม `↗`
7. กด `ดู Preview การสร้าง`
8. กด `สร้าง Hard Link จริง`

## หลักความปลอดภัย V1

- ไม่ลบไฟล์ต้นทาง
- ไม่ overwrite ไฟล์ปลายทางที่มีอยู่แล้ว
- Hard Link ต้องอยู่ไดรฟ์เดียวกัน
- ก่อนสร้างจริงมี preview, dry-run, boundary check
- มี `ตรวจไฟล์ตกค้าง` แบบรายงานอย่างเดียว ไม่ลบไฟล์
- มีปุ่ม `×` สำหรับถอด match ผิด โดยไม่ลบไฟล์

## เรื่องสำคัญของ Hard Link

Hard Link เปิดเหมือนไฟล์วิดีโอจริงและไม่กินพื้นที่เพิ่มแบบคัดลอกไฟล์ แต่ข้อมูลวิดีโอเป็นก้อนเดียวกัน

- ลบไฟล์ปลายทาง: ต้นทางไม่หาย
- ลบไฟล์ต้นทาง: ปลายทางยังเปิดได้ถ้ายังมี Hard Link อยู่
- แก้ไข/ตัดต่อ/Save ทับไฟล์ใดไฟล์หนึ่ง: ข้อมูลวิดีโอเดียวกันอาจเปลี่ยนด้วย

ใช้ไฟล์ Hard Link สำหรับเปิดดู/จัดชุดคลิป ไม่ใช้เป็นไฟล์ตัดต่อ

## ย้ายไปเครื่องอื่น

1. คัดลอกทั้งโฟลเดอร์แอพไปเครื่องใหม่
2. ติดตั้ง Node.js LTS ถ้าเครื่องนั้นยังไม่มี
3. เปิด `start-v1.cmd`
4. เปลี่ยน Google Sheet URL, โฟลเดอร์ต้นทาง, โฟลเดอร์ปลายทาง
5. กด `สแกน` ใหม่

ถ้าไม่อยากใช้ค่าเดิม ให้ดูตัวอย่างจาก `config.example.json`
